# Capstone: Design and Evaluate the "Smart Reminder" Experiment on Injaz

**Name:** Aleen Mohammed

## Project Overview

This project focuses on designing and evaluating a Smart Reminder experiment on Injaz. The experiment uses randomized experimentation and causal inference methods to measure the effect of reminders on user completion.

## Project Objective

The main objective is to determine whether the Smart Reminder improves completion and whether the observed improvement is practically significant.
